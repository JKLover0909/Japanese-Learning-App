# Documentation

This documentation covers how to develop and operate the Japanese kana practice MVP: anonymous learners, six lessons, and a separate admin statistics page.

- [Architecture](architecture.md) — application layout, data model, learning rules, and security.
- [HTTP API](api.md) — request and response contract shared by the FastAPI backend and frontend.
- [Development](development.md) — setup, tests, lint, lesson content, stable item keys, and migrations.
- [Operations](operations.md) — serving, LAN/tunnel access, backups and restore, upgrades, admin login setup, and usage data retention.

Start with the root [README](../README.md) for purpose, features, quick start, configuration, and project status.
